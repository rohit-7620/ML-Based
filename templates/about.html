✨ Key Features

🎯

Intelligent Grade Prediction

Dual-model approach using Logistic Regression and Gradient Boosting with confidence-based selection for optimal accuracy.

💬

Smart Doubt Triage

NLP-powered text classification with TF-IDF vectorization to automatically prioritize and route student queries.

🔀

Confidence-Based Routing

Data-driven threshold optimization that balances automation efficiency with prediction accuracy.

⚙️

Advanced Feature Engineering

Domain-specific features including engagement scores, urgency detection, and technical keyword analysis.

📈

Rigorous Evaluation

5-fold cross-validation, stratified sampling, and comprehensive metrics for robust model assessment.

🚀

Production-Ready API

RESTful Flask API with batch processing, model persistence, and comprehensive error handling.
