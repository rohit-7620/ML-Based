📊 Datasets

📈 Dataset 1: Student Grading Data

Tabular
Samples: 1,000 students
Features: 10 (7 original + 3 engineered)
Target: Grade (A, B, C, D)
Split: 70% train / 10% val / 20% test

Original Features:

  • Attendance Percentage
  • Quiz Average
  • Assignment Average
  • Midterm Score
  • Participation Score
  • Study Hours per Week
  • Previous GPA

Engineered Features:

  • Engagement Score: Attendance * 0.4 + Participation * 10 * 0.6
  • Academic Consistency: (Quiz + Assignment) / 2
  • Performance Trend: Midterm - Consistency

💬 Dataset 2: University Query Data

Text
Samples: 6,000 queries
Features: 1,005 (1000 TF-IDF + 5 engineered)
Target: Priority (High, Medium, Low)
Split: 80% train / 20% test

Text Features:

  • TF-IDF Vectorization: 1000 features, English stop words removed

Engineered Features:

  • Query Word Count: Number of words in query
  • Urgent Keywords: Detection of urgent/emergency terms
  • Technical Keywords: Portal/password/system terms
  • Urgency Score: Deadline-based urgency (0-3)
  • Department Encoding: Categorical encoding
